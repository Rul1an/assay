# Launch Definition

Accepted: 2026-09-17

The record of the decision is [issue #3098](https://github.com/Rul1an/assay/issues/3098).

> Assay is launched when a first-time user, on every platform named in `docs/getting-started/installation.md`, can:
>
> 1. install the pinned published release by the documented command;
> 2. run the nine golden-path steps (`docs/guides/agent-golden-path.md:47-55`) and get the documented stdout and exit codes;
> 3. produce one evidence bundle and verify it offline;
>
> and every sentence in `README.md`, `docs/getting-started/*` and `docs/mcp/quickstart.md` is true of the binary that user installed.
>
> The support commitment is `SECURITY.md:8` exactly as written: the current published release. Nothing beyond the three capabilities above is claimed by the act of launching.
